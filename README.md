# SQL Masterclass in Kannada

### To get access to the notbooks
1. Download the ***SQL Masterclass.dbc*** file
2. Go to your ***Databricks*** workspace
3. Clicks on the ***3 dots*** right side. Next to Send feedback.
4. Clicks on ***Import***.
5. Upload the ***SQL Masterclass.dbc*** file.

**Congratulations!!🥳 You got the notebooks...**
